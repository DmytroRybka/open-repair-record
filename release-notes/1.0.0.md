The first release of Open Repair Record: the open guide and the free report editor, also as a self-hosted copy.

**Run it inside your company**

```
docker run -d --name open-repair-record -p 8080:8080 --read-only --tmpfs /tmp \
  ghcr.io/dmytrorybka/open-repair-record-editor:1.0
```

Then open `http://your-server:8080/build/`. Or unpack `open-repair-record-onprem-1.0.0.zip` (check it against the
`.sha256` file) into any web server's document root; a `web.config` for IIS is included.

**What is in it**

- The report editor: a live check for contradictions and missing parts, print and PDF, JSON download and upload,
  messages for the contractor and the resident.
- The guide, five worked examples, the blank template, and format 1.0 with its JSON Schema.
- No outside requests (tested on every page), no analytics, no telemetry, no account. Static files only: records stay
  in each person's browser and on their device.
- The image: unprivileged nginx on port 8080, works read-only, `/healthz`, a strict Content-Security-Policy without
  `unsafe-eval`, amd64 and arm64.

Format 1.0 promise: every 1.x version only adds; files written for 1.0 keep working.
